# Interactive Text Analysis Platform (NLP)

## Project Overview

The Interactive Text Analysis Platform is a Natural Language Processing (NLP) application designed to analyze user text inputs and generate meaningful insights such as sentiment, emotions, and key phrases. The system processes large volumes of text efficiently and provides real-time visual analytics to support quick decision-making.

## Key Features

* Analyzed **1,000+ user text inputs** to extract:

  * Sentiment (Positive, Negative, Neutral)
  * Emotions
  * Key phrases
* Implemented advanced NLP models using **Hugging Face Transformers**
* Applied text preprocessing techniques:

  * Lemmatization
  * Stop word removal
  * N-gram extraction
* Improved data quality and model performance by **30%+**
* Generated dynamic visual dashboards:

  * Word Clouds
  * Emotion Distribution Charts
  * Sentiment Bar Graphs
* Delivered actionable insights in **under 5 seconds per input**

## Technologies Used

* Python
* Hugging Face Transformers
* NLTK / SpaCy
* Scikit-learn
* Pandas & NumPy
* Matplotlib / Seaborn / WordCloud
* Streamlit / Flask (if used)

## Project Workflow

1. User enters text input
2. Text preprocessing is applied
3. Transformer model analyzes sentiment and emotions
4. Key phrases are extracted
5. Results are displayed through interactive visual dashboards

## How to Run the Project

1. Clone the repository
2. Navigate to the project folder
3. Install dependencies:

```
pip install -r requirements.txt
```

4. Run the application:

```
streamlit run app.py
```

(or run main script if applicable)
